## What is being built

A preset is a `*.json` file in `$XDG_CONFIG_HOME/nixarchy/microvm/presets/`.
One `find` reads the folder. One strict parser in `Model.js` turns its output
into at most 9 presets plus per-file errors. The create form gets a first row,
"Start from a preset", where a bare `1` to `9` fills the form. The empty state
(no VMs) lists the same presets with the same digits. A pick reuses
`applyAgentReply` on a blank `emptyForm`, then `validateForm`, then the
existing review screen. No new file, no new setting, no new flake check, no new
QML component. `flake.nix`, `schema.json`, `manifest.json`, `Menu.qml` and
`Panel.qml` do not change.

## Approved decisions, carried over from the spec

**Intent decisions (owner approved 2026-11-17)**
1. A preset starts from a blank `emptyForm(kind)`, never from the current
   form, so the result is the same every time.
2. A preset's `name` is ignored; the cursor lands on the name field.
3. The label is the file name (without `.json`). No new key, so `schema.json`
   and `AGENT_FIELDS` stay equal *(checked: schema-fields)*.
4. The picker is a top row in the create form, keyed so typing is unaffected.
5. A preset cannot set `startNow`. It cannot carry `sshKey`, `describe` or
   `editing` either.
6. No off switch. No folder means no presets.
7. No named preset from the menu row or IPC. `Menu.wantsCreate` is untouched.

**Reading the folder**
- Argv is `Model.presetsArgv(configHome)`; `null` when `configHome` is empty.
  Exact shape in step 1. Run by name from `PATH`, array only, no `sh -c`.
- `find -L ... -type f` so a symlink is followed only to a regular file. A
  FIFO, socket, device, directory or dangling link is never `cat`'d.
  `timeout 2` bounds a hung mount.
- A file over 16 KiB is named but never read; its record body is the one byte
  `\x15`, which parses to `too large (over 16 KiB)`. A body over 16384
  characters gets the same message (a file that grew after the stat).
- Records are `RS name US body` (`\x1e` name `\x1f` body). A chunk without
  `\x1f` is ignored. A forged boundary can only mint a preset from the user's
  own folder and is accepted and tested, not prevented.
- Sort by file name; examine the first 32 entries; keep at most 9 valid
  presets (`MAX_PRESETS = 9`). Skipped ones are reported in the note.
- Label = file name without `.json`, through `sanitize(..., 32)`; empty
  becomes `(unnamed)`. Labels and errors are drawn `Text.PlainText`.
- A missing or empty folder, or a failed read, gives no output: no presets and
  no error.

**Per-file contract (`Model.parsePreset`)**
- Not valid JSON, or not an object (array, `null`): `not valid JSON`. The
  engine's own message is never shown.
- Unknown key: `unknown key "<sanitize(key, 24)>"`. Keys allowed are exactly
  `AGENT_FIELDS`. This rejects `startNow`, `sshKey`, `describe`, `editing` and
  `__proto__` with no extra code.
- Wrong type (any `rejected` entry from `applyAgentReply(reply, emptyForm())`):
  `wrong type: <key>`.
- Stricter than the agent gate: `shares` must be a real array of at most 16
  entries, each an object with exactly `source` and `mountPoint`, both
  strings; string lengths may not exceed `name` 64, `template` 32,
  `reasoning` 280, share parts 4096 (rejected, never truncated). Every error
  is a fixed phrase naming a key, never a value.
- No required keys: `{}` is a valid blank preset. `name` and `reasoning` are
  type-checked then ignored. `sshPort: null` is accepted.
- Ranges and the template are not duplicated; `validateForm` checks them on the
  same path as typed input, against the live template list, which arrives
  asynchronously.

**Form and errors**
- `Model.presetForm`: `emptyForm(kind)` from `reply.kind`; apply
  `applyAgentReply`; set `name = ""`, `describe = ""`; `startNow` stays true,
  `sshKey` stays empty; `preset` is set to the label.
- `emptyForm` gains `preset: ""` (strings and bools only).
- Errors live in `MicrovmState.presetErrors`, never on `agentError` or
  `lastError`. One dim caption (`Model.presetNote`) under the preset row and
  under the preset line in the empty state; at most 2 errors then `+n more`;
  each clamped to 120 characters.
- The row shows when presets or errors exist. No folder and no files: no row,
  no caption, the plugin looks as today. It never shows on an edit.

**When presets are read (no timer)**
- `MicrovmState.readPresets()` guarded by `if (presetsProcess.running)
  return`. Called from exactly two places: `onActiveChanged` when `active`
  becomes true (the first surface to open, `active` is `views > 0`), and the
  `u` key beside `MicrovmState.refresh()`.
- Not in `probe()` or `refresh()` (both run on the bar's timer). Not in
  `openForm` (a late result would shift the field indexes). No `FileView`
  watch.
- A cold direct-to-form open (`'{"create":true}'` on a closed plugin) sees no
  presets; the row shows from the next form open. Accepted.
- `CreateForm.start()` snapshots `MicrovmState.presets` and `presetErrors`
  into `root.presets` and `root.presetErrors`. A read landing mid-form changes
  nothing.
- `statusJson()` gains `presetReads` (reads started), `presets` and
  `presetErrors` (counts).

**The picker**
- `FORM_FIELDS` gets one entry, first: `{ key: "preset", widget: "preset",
  label: "Start from a preset", create: true, presets: true }`.
  `visibleFields` hides it unless `state.presets > 0` or `state.presetErrors
  > 0`.
- On the preset row only, a bare `1` to `9` picks preset N, through
  `Model.presetIndex(text, count)` (-1 for `0`, `10`, a letter, or N above the
  count), from one new branch in `CreateForm.navKey`, guarded by
  `root.current.widget === "preset"`. The preset row is not `takesText`, so no
  digit reaches a text field through it. Alt+digit is not used.
- `CreateForm.pickPreset(i)`: first `MicrovmState.resetAgent(surface)` (cancels
  a pending agent call, frees `describe`); then `setForm(Model.presetForm(p))`,
  clear `reasoning`, `begin()`; cursor to `name` by `fieldIndexOf(fields,
  "name")`; `touched` set to the keys the preset supplied except `name`;
  `attempted` stays false. A pick replaces everything typed so far.
- Submit stays separate: `enter`, then the review screen for a permanent VM.
- Display: one wrapped caption under the row, `1 python-4g   2 web   ...`,
  in the existing caption font with `Color.*` and `Style.*` tokens. No mouse
  targets.
- Hint line when the row is current: `1-9 pick   tab next   esc cancel`.
- `c` still opens at `name`; the row is above it, reached by `up` or
  `shift+tab`. Presets sort by file name, so a prefix such as `10-box.json`
  pins a place; the docs say so.

**The empty state**
- `Model.startHere(state)` is true exactly when `emptyText` reaches its last
  branch. `emptyText` calls `startHere`, so they cannot disagree.
- With `state.presets > 0` the last line becomes `No VMs yet — press c to
  create one, or start from a preset`. The line `1 python-4g   2 web   ...`
  and the errors caption go below it in the same column.
- `handleTextKey` gets one branch: when `startHere` holds and
  `presetIndex(key, presets.length) >= 0`, call `openForm("disposable",
  "name")`, then `createForm.pickPreset(i)`. While the filter field has focus
  the key catcher is blocked, so digits type into the filter. `openForm` is
  already gated by the upstream verdict ("checking nixarchy…").

**Docs and checks**
- `SHORTCUTS` gets two entries, key labels at most 12 characters: group
  "Form", keys `1-9`, "On the preset row: fill the form from that preset";
  group "All VMs", keys `1-9`, "With no VMs: create from that preset".
- README (key tables, a "Presets" section, requirements, Safety bullet),
  `docs/usage.md` (an everyday task and a troubleshooting entry) and
  `AGENTS.md` (one `(by hand)` rule, the Layout row for `Model.js`).
- `flake.nix` unchanged: the touched runtime files are already in `files`.
  No new `# check:` block.

**Bounds, as the owner decided on 2026-11-17**
- Each file is capped (16 KiB), the work is capped (2 s), what is kept is
  capped (32 examined, 9 shown). `find`'s output is not capped by count; the
  time bound is enough for a folder the user owns. No streaming reader.

## Repo traps that apply

- **Logic goes in `Model.js`, with a Node test.** QML only wires and draws.
  QML never builds the argv, a label, a note, or the digit-to-index choice.
- **Argv only, by name from `PATH`.** `timeout`, `find`, `cat` are new
  requirements: the README lists them. A missing one fails silently as "no
  presets".
- **No hardcoded colours** *(checked: colours)*. Use `Color.*`, `Style.*`,
  `root.dim`, `root.foreground`, `Commons.Color.*` exactly as the neighbouring
  `Text` items in `CreateForm.qml` do. No hex, no colour names.
- **One `singleton MicrovmState`** *(checked: singleton)*. The read, the
  results and the counters live there once. Neither surface keeps its own.
- **Keep-loaded surfaces.** `open()` runs again while open and must not touch
  the stream or the log. Presets are read on the first open and on `u`, not in
  `open()` itself beyond what `active` already triggers.
- **Nothing polls while every surface is closed.** No timer, no `FileView`,
  nothing in `probe()` or `refresh()`.
- **Sequence wrappers.** A list read through a QObject `var` property is a Qt
  sequence wrapper: check `.length`, never `Array.isArray`. Copy
  `MicrovmState.presets` into `root.presets` with a plain loop or
  `Array.prototype.slice.call`, and reassign, never mutate in place.
- **A `property var` holding a list or map is reassigned**, never mutated, or
  bindings do not update.
- **`implicitHeight` never reads `height`.** The new rows add to
  `fieldsColumn.implicitHeight` only through their own content.
- **No symlinks in the repository** *(checked: symlinks)*. The test fixtures
  for FIFOs and links are live steps in the user's folder, not committed files.
- **`schema.json` and `AGENT_FIELDS` may not name different fields**
  *(checked: schema-fields)*. Neither changes.
- **A user-visible change updates `docs/usage.md` and the README in the same
  PR.** Step 4 does it; the PR holds all four steps.
- **Tests that assume `describe` is first.** `tests/model/form.test.js:267`
  and `:295` (`fieldIndexOf(fields, "describe") === 0`) and anything pinning
  exact `emptyForm` or `visibleFields` key lists must be updated in the same
  commit as the change that breaks them. The new row is hidden when the state
  has no `presets` or `presetErrors`, so most existing assertions pass
  unchanged; the ones that do not are fixed in step 1.
- **After each step run `node tests/run.js`.** After steps 2 and 3 also run
  `nix build`. After step 4 also run `nix flake check`.

   **The contracts**

   - **`MAX_PRESETS = 9`, `PRESET_EXAMINED = 32`, `PRESET_MAX_BYTES = 16384`.**
   - **`presetsArgv(configHome)`.** `h = trim(configHome).replace(/\/+$/, "")`;
     `null` when empty. Otherwise exactly:

     ```text
     ["timeout", "2", "find", "-L", h + "/nixarchy/microvm/presets",
      "-maxdepth", "1", "-type", "f", "-name", "*.json", "!", "-name", ".*",
      "(", "-size", "+16k", "-printf", "\\036%f\\037\\025", "-o",
      "-printf", "\\036%f\\037", "-exec", "cat", "{}", ";", ")"]
     ```

     The parentheses matter: without them `-o` splits the whole expression
     and the second branch runs for directories, hidden and non-JSON files.

     In JS source the `-printf` strings are `"\\036%f\\037\\025"` and
     `"\\036%f\\037"` (a backslash then octal digits, for find to expand), the
     same escaping `sshKeysArgv` uses for `\n`.
   - **`parsePreset(text)`** returns `{ ok, reply, error }`; on success `error`
     is `""` and `reply` is the parsed object; on failure `ok` is false,
     `reply` is `null` and `error` is the cause only, with no file label.
     Order of checks:
     1. `text === "\x15"` or `text.length > PRESET_MAX_BYTES`: `too large (over
        16 KiB)`.
     2. Not valid JSON, or not a plain object (an array or `null`):
        `not valid JSON`. Use a preset-local check (`JSON.parse` in a
        `try`, then `v && typeof v === "object" && !Array.isArray(v)`), not
        `parseObject` (`:1842`): it also rejects any object with a numeric
        `length`, which would turn `{"length":0}` into `not valid JSON`
        instead of `unknown key "length"`.
     3. For each own key in file order: if not in `AGENT_FIELDS`, error
        `unknown key "` + `sanitize(key, 24)` + `"`.
     4. Strict `shares`: not a real array (`Array.isArray`) is `wrong type:
        shares`; more than 16 entries is `too many shares (over 16)`; an entry
        that is not a plain object, has any key other than `source` and
        `mountPoint`, or has a non-string part is `wrong type: shares`.
     5. Length limits on strings: `name` 64, `template` 32, `reasoning` 280,
        each share part 4096. Over is `too long: <key>` (key is `shares` for a
        share part). Rejected, never truncated.
     6. `applyAgentReply(reply, emptyForm())`: the first `rejected` key gives
        `wrong type: <key>`.
     No error string contains a value from the input.
   - **`parsePresets(raw)`** returns `{ presets, errors, more }`.
     - Split `String(raw)` on `"\x1e"`; for each chunk find the first `"\x1f"`;
       no `\x1f` means ignore the chunk. `file = chunk.slice(0, i)`, `body =
       chunk.slice(i + 1)`.
     - Sort entries by `file` (plain code-unit compare). Examine the first
       `PRESET_EXAMINED`; entries beyond count into `more`.
     - Label: `sanitize(file.replace(/\.json$/, ""), 32) || "(unnamed)"`.
     - For each examined entry run `parsePreset(body)`. A failure appends
       `label + ".json: " + error` to `errors`. A success appends `{ label,
       reply }` to `presets` until there are `MAX_PRESETS`; further valid ones
       count into `more`.
     - An empty body is `not valid JSON`.
   - **`presetForm(preset)`** where `preset` is `{ label, reply }`. Start
     `emptyForm(preset.reply.kind === "permanent" ? "permanent" :
     "disposable")`, run `applyAgentReply(preset.reply, thatForm).form`, then
     set `name = ""`, `describe = ""`, `preset = preset.label`. Returns the
     form. `startNow` stays true, `sshKey` stays empty, nothing is validated
     here.
   - **`presetTouched(reply)`** returns a map `{ key: true }` of the form keys
     the preset supplied: every own key of `reply` that is in `AGENT_FIELDS`,
     except `name` and `reasoning`. `shares` and `sshPort` map to themselves.
     `pickPreset` uses it so a bad supplied value is red at once.
   - **`presetIndex(text, count)`** returns `n - 1` when `text` is exactly one
     of `"1"` to `"9"` and `n <= count`, otherwise `-1` (`"0"`, `"10"`, a
     letter, empty, undefined).
   - **`presetLine(presets)`** returns the picker caption: `"1 " + label` for
     each, joined by three spaces, e.g. `1 python-4g   2 web`.
   - **`presetNote(errors, shown, more)`** returns `""` when there are no
     errors and `more` is 0. Otherwise it joins, with three spaces, up to two
     of: `N preset(s) skipped: ` + the first two errors joined by `"; "` (each
     clamped to 120 characters with an ellipsis) + `"; +n more"` when there are
     more than two; and, when `more > 0`, `shown + " of " + (shown + more) + "
     shown"`. `1 preset skipped` is singular. This signature differs from the
     spec's `presetNote(count, errors)` only by carrying `shown` and `more` for
     the "9 of 14 shown" text the spec also requires.
   - **`startHere(state)`** is true when `state.everLoaded && state.reachable
     && !state.filtered && !state.upstreamError && !state.listError &&
     state.showStopped`. `emptyText` calls it.
