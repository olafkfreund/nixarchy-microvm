# Plan: the menu as a card-sized layer

Branch `feat/50-card-menu`. Code starts only after PR #47 merges. The branch
is then rebased onto `main`; its line numbers below are on
`fix/46-review-findings`, which equals `main` after that merge.

Each step is one commit, with a subject citing the step, for example
`feat: card-sized menu layer (#50, step 2)`.

## Approved decisions, carried over from the spec

- **The menu window is the card.**
  - It is anchored at the top and centred, sized and placed by
    `Model.menuGeometry`.
  - There is no scrim and no full-screen `MouseArea`.
- **Keyboard focus** follows the shell's `Ui/KeyboardPanel.qml:150-160`:
  - while open, `Exclusive` for a 75 ms prime, then `OnDemand`;
  - when closed, `None`.
- **A click outside closes it** through `HyprlandFocusGrab`, armed only once
  the window is mapped and the prime is done.
- **The fallback** applies if the live checks fail. It is today's single
  full-screen `PanelWindow` with only the scrim removed: no grab, no second
  window. A switch to it is a recorded deviation.
- **No dimming setting.** Captures are retaken at the next capture pass.

## Repo traps

- **Every colour is read as `Commons.Color`** (#45, the Qt 6.12 shadowing).
- **The sizing rule:** no render transform; the card derives from the
  screen and the text size.
- **`Quickshell.screens` is a sequence wrapper:** check `.length`.
- **Logic goes in `Model.js`, with a Node test.**
- **No new root files.**
- **After each step,** run `node tests/run.js`. After steps 2 and 3, run
  `nix flake check` too.

## Steps

1. **`Model.js`: add `menuGeometry` after `cardWidth` (`Model.js:555-560`).**
   - **Signature:** `menuGeometry(screenW, screenH, minW, maxW,
     viewNaturalH, insetX, insetY, gaps)`, returning `{ width, height, top }`.
   - **When both `screenW > 0` and `screenH > 0`:**
     - `viewW = cardWidth(screenW, 0.55, minW, maxW)`;
     - `width = min(viewW + insetX, round(screenW * 0.9))`;
     - `height = min(viewNaturalH + insetY, round(screenH * 0.85))`;
     - `top = max(gaps, round((screenH - height) / 3))`.
   - **Otherwise:** `width = min(minW, maxW) + insetX`,
     `height = viewNaturalH + insetY`, `top = gaps`.
   - Every result is a whole number of pixels.
   - **Tests** in `tests/model/rows.test.js`, next to the `cardWidth`
     tests:
     - 2560x1440 with typical values: the width is 0.55 of the screen
       clamped by min/max plus the inset, and `top` is a third of the
       remaining space;
     - an 800x500 screen hits both caps;
     - screen 0x0: the floor width, the natural height, `top = gaps`, and
       nothing is 0.
   - → `node tests/run.js`

2. **`Menu.qml`: the card-sized layer (`Menu.qml:25-31`, `:60-66`,
   `:89-151`).**
   - **`:28-31`.** Replace the `viewWidth` comment and property with:
     - `readonly property var screenFor: root.targetScreen ||
       (Quickshell.screens.length > 0 ? Quickshell.screens[0] : null)`;
     - `readonly property var geometry: Model.menuGeometry(screenFor ?
       screenFor.width : 0, screenFor ? screenFor.height : 0,
       Style.space(560), Style.space(1100), view.implicitHeight,
       card.contentLeftInset + card.contentRightInset,
       card.contentTopInset + card.contentBottomInset, Style.gapsOut)`.

     The 1100 comment (matching nixarchy.pkg's menu) stays.
   - **Focus prime.**
     - Add `property bool focusPrimed: false` and a `Timer { id:
       focusPrimeTimer; interval: 75; onTriggered: if (root.opened)
       root.focusPrimed = true }`.
     - In `open()` (`:60`), set `root.focusPrimed = false` before
       `root.opened = true`.
     - In `close()`, stop the timer and set `focusPrimed = false`.
   - **`PanelWindow` (`:89-101`).**
     - `screen: root.screenFor`;
     - `anchors { top: true }`;
     - `margins.top: root.geometry.top`;
     - `implicitWidth: root.geometry.width`;
     - `implicitHeight: root.geometry.height`;
     - `WlrLayershell.keyboardFocus: root.opened ? (root.focusPrimed ?
       WlrKeyboardFocus.OnDemand : WlrKeyboardFocus.Exclusive) :
       WlrKeyboardFocus.None`;
     - `onBackingWindowVisibleChanged: if (backingWindowVisible &&
       root.opened) focusPrimeTimer.restart()`;
     - `onVisibleChanged` is kept.
   - **Delete:** the scrim `Rectangle` (`:103-106`), the full-screen
     `MouseArea` with its comment (`:108-113`), and the card's
     `MouseArea { onClicked: {} }` (`:128`).
   - **`card` (`:115-126`).** `anchors.fill: parent` replaces
     `width`/`height`/`horizontalCenter`/`y`. Colour, border, padding and
     radius stay.
   - **The grab.** Add, as a child of `root`:

     ```qml
     HyprlandFocusGrab {
       active: root.opened && panel.backingWindowVisible && root.focusPrimed
       windows: [panel]
       onCleared: root.close()
     }
     ```

     Add a one-line comment pointing at `Ui/PopupCard.qml:87-94`.
   - **Update the header comment** (`:10-14`): the menu is card-sized, and
     a click outside closes it.
   - → `nix build`, then a quick live smoke check with the shell stopped
     (AGENTS.md "Verifying live" step 1). The menu opens, and is not closed
     by itself after 3 s. The full live check is in Verification.
   - Traps: `Commons.Color`; no logic beyond bindings; keep-loaded `open()`
     stays a clean slate.

## Deviations recorded during implementation

- **Step 3** also updated two places the plan did not list: the comment at
  `Panel.qml:11` ("full-screen menu"), and the showcase page
  `docs/index.md:137-142` (the text, alt text and caption). Both described
  the full-screen layer. `docs/img/menu.png` still shows the scrim, until the
  next capture pass (owner decision).
- **Fallback detail** (Codex plan review). If the fallback is ever used, the
  restored card needs explicit bindings, because step 2 removed
  `root.viewWidth`:
  - `width: root.geometry.width` and `height: root.geometry.height`;
  - `anchors.horizontalCenter: parent.horizontalCenter`;
  - `y: root.geometry.top`.

  The docs would then say "not dimmed" without "card-sized".
- **The fallback shipped (live check, 2026-11-16).** Steps 2's card-sized
  layer did these things:
  - it opened at card size (1132x225 on DP-1);
  - it stayed open;
  - it took keys, so `?` opened the sheet.

  But a click outside, on Chrome on DP-3, both closed the menu *and*
  activated Chrome: the Hyprland focus grab clears on that click but lets it
  through. That breaks the intent's "the click does nothing else".

  So `Menu.qml` is now the approved fallback:
  - one full-screen `PanelWindow`, `Exclusive` keyboard focus, as before;
  - a full-screen `MouseArea` closes the menu, and the card swallows its
    own clicks;
  - **no scrim**;
  - the card is sized and placed by `menuGeometry` (step 1), with the
    explicit bindings above;
  - the focus prime and the grab are removed.

  Live, with the fallback:
  - the layer is full-screen and nothing is dimmed;
  - a click outside on the menu's monitor closes it, and no window is
    activated;
  - a click on the *other* monitor neither closes it nor reaches the app.
    That is the same as before #50, because the layer covers its own
    monitor only.

  AGENTS.md's `Menu.qml` row and the "Verifying live" note now describe
  the full-screen, undimmed layer.
